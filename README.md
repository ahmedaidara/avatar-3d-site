# Avatar 3D Site

Site HTML simple et moderne pour afficher un avatar 3D créé avec [Avaturn](https://avaturn.me).

## Utilisation

1. Télécharge ton fichier `.glb` depuis Avaturn.
2. Renomme-le en `ton-avatar.glb` et place-le dans ce dépôt (ou modifie le `src` dans `index.html`).
3. Active GitHub Pages sur la branche `main` pour l'héberger gratuitement.

## Fonctionnalités

- Affichage 3D interactif avec model-viewer
- Rotation automatique
- Contrôles caméra (souris / tactile)
- Boutons Face / Profil / Dos
- Design responsive
